Inhalte

Was auf Ihre Website gehört

  • Telefonnummer in jedem Bildschirm

    Wer einen Handwerker sucht, will meist sofort jemanden sprechen. Die Nummer steht oben und ist auf dem Handy antippbar.

  • Referenzbilder Ihrer Arbeiten

    Fotos überzeugen mehr als jede Beschreibung. Ich ordne sie nach Leistung, damit Besucher schnell finden, was sie suchen.

  • Ein Knopf für die Offerte

    Ein kurzes Formular fragt nach den Angaben, die Sie für eine Offerte brauchen. Das spart Ihnen Rückfragen.

  • Ihr Einzugsgebiet

    Welche Gemeinden Sie bedienen, steht klar auf der Seite. Das hilft Besuchern und der Suche bei Google.

  • Jede Leistung auf eigener Seite

    Küchen, Bäder oder Fassaden: Im Paket Standard bekommt jede Leistung eine eigene Seite. So finden Besucher genau die Arbeit, die sie suchen.

Fragen

Was Sie sich vielleicht fragen

Ich habe kaum Fotos meiner Arbeiten. Geht das trotzdem?

Ja. Für den Entwurf reichen wenige Bilder. Einen Fotografen kann ich organisieren, die Kosten richten sich nach dem Aufwand.

Muss ich die Texte selbst schreiben?

Nein. Vorhandene Texte bereite ich im Paket auf. Texte von Grund auf schreibe ich für CHF 150 pro Seite.

Werde ich damit bei Google gefunden?

Im Paket Standard richte ich Ihr Google-Unternehmensprofil ein und lege die Grundlagen für die Auffindbarkeit. Einen bestimmten Platz in den Suchergebnissen kann niemand versprechen.
